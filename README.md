Siv3D 大相撲 物理演算・難易度選択版Siv3Dの2D物理演算エンジン（P2D）をコアに据えた、本格的な相撲アクションゲームです。力士の「重さ」や「粘り」を物理パラメータとして定義することで、指先から伝わるような重厚な押し合いを実現しました。概要プレイヤーは青い力士（Royalblue）を操作し、土俵（Dohyo）の上で敵の赤い力士（Crimson）と対峙します。相手を土俵の外へ押し出すか、あるいは寄り切ることで勝利となります。場所（15日間）を通じて、勝ち越しを目指しましょう。特徴的な機能1. 物理演算による「重厚な」ゲームプレイ質量（Mass）と抵抗（Damping）: 単なる座標移動ではなく、力士に質量と空気抵抗を設定。これにより、ぶつかった際の衝撃や、土俵際での踏ん張りが物理的に計算されます。FixedRotation: 力士の体が回転しないよう固定することで、相撲特有の「正面から向き合う」挙動を維持しています。2. 3段階の戦略的難易度設定タイトル画面で難易度を選択でき、それによって敵力士の「物理特性」が劇的に変化します。難易度敵の質量敵の抵抗(Damping)敵の推進力解説初級 (Easy)0.8倍 (軽量)8.0 (高い)8,000動きが鈍く、軽く突くだけで大きく後退します。中級 (Normal)1.0倍 (標準)5.0 (標準)15,000均衡した押し合いが楽しめる標準的なモード。上級 (Hard)1.5倍 (重量)2.0 (低い)25,000重くて速い。横綱級の鋭い踏み込みを見せます。3. 取組のライフサイクル管理動的初期化: SetupMatch 関数により、毎日の取組開始時に P2World をクリーンアップ。メモリリークや物理オブジェクトの重複を防ぎ、安定した動作を保証します。シーン遷移: タイトル → 取組（Game） → 結果（Result）のループにより、場所の流れをシミュレートしています。操作方法矢印キー (↑↓←→): 自力士の移動（力を加える）マウス左クリック: GUIボタンの操作（難易度選択、場所開始、次へ）開発環境Framework: Siv3D (OpenSiv3D v0.6.x 以降)Language: C++20エンジニア向けノート：物理演算の調整について本作品では applyForce による力の加算を採用しています。setVelocity（速度を直接書き換える）ではなく applyForce を使うことで、物体が持つ慣性を殺さずに、よりリアリティのある「押し合い」を表現しています。上級モードでは敵の Damping を下げることで、慣性が強く働き、一度勢いがつくと止めるのが難しい設計になっています。エンジニアの独り言：難易度によって敵の「質量」を変えるというアプローチは、プレイヤーに「情報の変化」ではなく「感覚の変化」を与えます。初級で勝てたプレイヤーが、上級で敵の重さに驚愕する。これこそが、物理エンジンをゲームロジックに組み込む最大の面白さですね！
